# Izdaje dokumentacije

V tej mapi trenutno ni potrjenih izdaj ali PDF.

Po potrditvi se za izdajo zabeležijo datum, različica, status, odgovorna oseba in izvorni commit. PDF se pripravi iz iste vsebine in shrani pod jasnim imenom, na primer Projekt_Odprta_sola_V6_2026-10-05.pdf. Primer imena ni že izdana datoteka.

Delovni osnutki ostajajo v ustreznih mapah dokumentacije. Starih poslanih dokumentov se ne nadomesti brez nove različice. Javna izdaja je označena kot javna različica, če se razlikuje od internega izvirnika.

Potrditev vsebine in objava PDF sta ločena od tehničnega merge v GitHubu.
